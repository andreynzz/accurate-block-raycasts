# Accurate Block Raycasts

A Fabric mod for Minecraft Java Edition 26.3 that will make intentional visual
openings in supported blocks affect projectile and line-of-sight raycasts.

The current foundation contains server-safe geometry primitives only. Gameplay
integration is intentionally not implemented yet.

See [the architecture](docs/ARCHITECTURE.md) and [development roadmap](docs/ROADMAP.md)
for established decisions and the incremental plan.
